## 📌 Project Overview

This project explores the potential application of microstrip patch antenna technology for non-invasive brain tumor detection research.

The project focuses on designing and analyzing a microstrip patch antenna using CST Studio Suite and studying its electromagnetic interaction with a head phantom model.

The reflection coefficient (S11) is analyzed to investigate changes in electromagnetic responses under different simulated tissue conditions.

The objective is to explore the potential of microwave-based sensing techniques for biomedical applications.

## 🎯 Project Objectives

- Design and simulate a microstrip patch antenna.
- Develop a head phantom model for electromagnetic analysis.
- Study antenna performance using CST Studio Suite.
- Analyze the reflection coefficient (S11).
- Investigate electromagnetic response variations under different simulated conditions.
- Explore potential applications in biomedical sensing and microwave imaging research.

## ⚙️ Project Methodology

### Antenna Design

Design a microstrip patch antenna with appropriate substrate material, conductive patch, ground plane, and feeding structure.

### Head Phantom Modeling

Develop a head phantom model using suitable electromagnetic properties to represent the modeled tissue conditions.

### Simulation Setup

Configure the antenna, phantom, boundaries, and simulation parameters in CST Studio Suite.

### S-Parameter Analysis

Analyze the reflection coefficient (S11) to evaluate antenna response under the selected simulation conditions.

### Result Comparison

Compare simulated responses for different modeled conditions to investigate whether measurable electromagnetic differences exist.
